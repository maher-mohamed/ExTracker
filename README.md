# 🚀 ExTracker - Premium Expense Manager

**ExTracker** is a sleek, modern, and high-performance financial management application built with **Flutter** and **Firebase**. Designed with a premium "Ocean Blue" aesthetic, it provides users with a seamless experience for tracking expenses, analyzing spending habits, and managing personal finances.

![App Header](https://raw.githubusercontent.com/flutter/flutter/master/packages/flutter_tools/static/flutter_logo_825.png)

## ✨ Key Features

- **💎 Premium UI/UX:** Stunning "Ocean Blue" theme with glassmorphism effects and smooth micro-animations.
- **📊 Advanced Analytics:** Interactive Pie Charts and Line Graphs for weekly spending trends.
- **🔐 Secure Authentication:** Firebase-powered Email & Google Sign-In with secure password reset functionality.
- **👤 Profile Management:** Customizable user profile with real-time photo uploads (Firebase Storage) and username updates.
- **🌓 Dark Mode Support:** Full support for both Light and Dark themes, adapting seamlessly to system settings.
- **📅 Real-time Sync:** Instant data synchronization across devices using Firebase Cloud Firestore.

## 🛠 Tech Stack

- **Framework:** [Flutter](https://flutter.dev/) (Dart)
- **Backend:** [Firebase](https://firebase.google.com/) (Auth, Firestore, Storage)
- **State Management:** [Provider](https://pub.dev/packages/provider)
- **Data Visualization:** [fl_chart](https://pub.dev/packages/fl_chart)
- **UI Components:** Glassmorphism, Shimmer effects, and Google Fonts (Outfit/Inter).

## 🚀 Getting Started

### Prerequisites
- Flutter SDK installed.
- Android Studio or VS Code with Flutter extensions.
- A Firebase project set up.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/expense_tracker_app.git
   ```
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the application:
   ```bash
   flutter run
   ```
